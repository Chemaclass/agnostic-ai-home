Set up https://github.com/Chemaclass/agnostic-ai-home as my global AI config. Clone it, then follow its SETUP.md step by step.

The agent installs agnostic-ai, links the clone, detects your tools, keeps your existing skills, and verifies the sync.

How it works

One git clone is the source. A symlink makes it the agnostic-ai home. Sync reads the shared specs plus your private local/ layer and writes real files into each tool.

One spec, three native files

Each tool wants a different shape. The spec says it once, with per-tool values where tools differ. This is agents/locator.md and what sync writes from it.

---
name: locator
tools: [Read, Grep, Glob, Bash]
model: {claude: haiku, codex: gpt-6-luna}
effort: {claude: low, codex: low}
readonly: true
---
You find code. You never edit files...

Claude Code

~/.claude/agents/locator.md
tools: [Read, Grep, Glob, Bash]
model: haiku
effort: low

Codex

~/.codex/agents/locator.toml
model = "gpt-6-luna"
model_reasoning_effort = "low"
sandbox_mode = "read-only"

Cursor

~/.cursor/agents/locator.md
readonly: true

A field a tool cannot honor is dropped with a note at sync time, never silently.

Text outside the managed block stays yours. Sync records what it owns in ~/.agnostic-ai/state/ and removes only that.

Where tools really differ

Sync never translates hook events. So the shell guard ships as two specs over one script: Claude and Codex share PreToolUse, Cursor needs beforeShellExecution and a JSON reply.

hooks/guard-shell.yaml

targets: [claude, codex]
event: PreToolUse
matcher: Bash
command: "$HOME/.agnostic-ai/scripts/guard-shell.py"

hooks/guard-shell-cursor.yaml

target: cursor
event: beforeShellExecution
command: "$HOME/.agnostic-ai/scripts/guard-shell.py"

It blocks force pushes without a lease, recursive rm with a glob, printing secret files, and em or en dashes in published text.

Make it yours without forking

Never edit tracked files. Put your changes in local/. A local spec with the same kind and name replaces the shared one; a new name is added. git pull never conflicts.

local/targets                     # claude,codex,gemini
local/AGNOSTIC_AI.md              # appended after the shared agreements
local/skills/work-notes/SKILL.md  # a private skill
local/agents/reviewer.md          # replaces the shared reviewer

To switch a shared skill, agent, or hook off, copy it into local/ and add targets-exclude: [claude, codex, cursor]. Run agnostic-ai list --global to see which layer wins.

Update

git -C ~/.agnostic-ai pull --ff-only && ~/.agnostic-ai/sync.sh

New shared skills arrive with the pull. For each local replacement, diff the shared file and merge what you want.
