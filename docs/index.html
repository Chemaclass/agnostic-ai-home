How it works

Your clone holds everything. ~/.agnostic-ai is a symlink to it, so both paths point at the same files. Your own changes go in ~/.agnostic-ai/local/, a gitignored folder inside the clone.

~/Code/agnostic-ai-home/~/.agnostic-ai links here
├── AGNOSTIC_AI.md            # shared, tracked by git
├── skills/ agents/ hooks/    # shared, tracked by git
└── local/                    # yours: gitignored, still synced

Sync reads both layers through the link and writes real files into each tool.

One spec, three native files

Each tool wants a different shape. The spec says it once, with per-tool values where tools differ. A field a tool cannot honor is dropped with a note at sync time, never silently.

agents/locator.mdsource
---
name: locator
tools: [Read, Grep, Glob, Bash]
model: {claude: haiku, codex: gpt-6-luna}
effort: {claude: low, codex: low}
readonly: true
---
You find code. You never edit files...
~/.claude/agents/locator.mdClaude Code

effort: low
~/.codex/agents/locator.tomlCodex

~/.cursor/agents/locator.mdCursor

Text outside the managed block stays yours. Sync records what it owns in ~/.agnostic-ai/state/ and removes only that.

Where tools really differ

Sync never translates hook events. So the shell guard ships as two specs over one script: Claude and Codex share PreToolUse, Cursor needs beforeShellExecution and a JSON reply.

hooks/guard-shell.yamlClaude, Codex
targets: [claude, codex]
event: PreToolUse
matcher: Bash
command: "$HOME/.agnostic-ai/scripts/guard-shell.py"
hooks/guard-shell-cursor.yamlCursor
target: cursor
event: beforeShellExecution
command: "$HOME/.agnostic-ai/scripts/guard-shell.py"

It blocks force pushes without a lease, recursive rm with a glob, printing secret files, and em or en dashes in published text.

Make it yours without forking

Never edit tracked files. Put your changes in ~/.agnostic-ai/local/. A file there with the same kind and name as a shared spec replaces it; a new name is added. git pull never conflicts.

~/.agnostic-ai/local/gitignored
targets                      # claude,codex,gemini
AGNOSTIC_AI.md               # appended after the shared agreements
skills/work-notes/SKILL.md   # a private skill
agents/reviewer.md           # replaces agents/reviewer.md

To switch a shared skill, agent, or hook off, copy it into the same path under local/ and add targets-exclude: [claude, codex, cursor]. Run agnostic-ai list --global to see which layer wins.

Update

shellany directory
git -C ~/.agnostic-ai pull --ff-only && ~/.agnostic-ai/sync.sh

New shared skills arrive with the pull. For each local replacement, diff the shared file and merge what you want.
